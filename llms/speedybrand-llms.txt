# SpeedyBrand (Speedy)

> SpeedyBrand, which ships as "Speedy", is an AI-powered content marketing and SEO
> platform that generates SEO-optimized blog posts, social posts, AI images and Google
> Ads copy, plus keyword research, competitor analysis, technical SEO audits and
> backlink recommendations. It produces content across 100+ regions and languages and
> publishes one-click to WordPress, Webflow, Shopify, LinkedIn, X/Twitter, Instagram
> and Facebook, with Google Search Console for analytics. Founded December 2022 in
> San Francisco; raised $2.5M led by GV (Google Ventures) with Y Combinator.

## Agent-relevant status

SpeedyBrand has NO reachable public API. This file is generated by API Evangelist from
the catalog profile and live probes — it is not published by SpeedyBrand.

- There is no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection or JSON Schema at any
  SpeedyBrand host.
- There is no MCP server and no A2A agent card.
- `api.speedybrand.io` still resolves and completes a TLS handshake but never returns an
  HTTP response. It formerly fronted SpeedyBrand's ChatGPT plugin.
- `learn.speedybrand.io`, the documented help centre linked from the site nav as
  "Learn", returns nginx 502 Bad Gateway on every path.
- The `SpeedyBrand/docs` GitHub repository is an unmodified Mintlify Starter Kit. Its
  `api-reference/openapi.json` is Mintlify's sample "OpenAPI Plant Store" spec pointing
  at `sandbox.mintlify.com`; it does NOT describe SpeedyBrand and must not be treated as
  a SpeedyBrand contract.
- The only programmatic surface is a third-party one: a "Speedy" Zapier app exposing a
  "New Blog Post" trigger, published inside Zapier rather than on a first-party
  developer site.

An agent cannot integrate with SpeedyBrand programmatically today. Use the web
application, or the Zapier trigger for publishing automation.
